# Contributing

You have a prompt that actually survived contact with reality? Share it.

## How

1. Fork, branch, add file to the right folder (`coding/`, `writing/`, etc.). If unsure, `productivity/`.
2. Format:

```md
# Your-Name

> One-line hook — what job does it do, in plain English.

---
**System Prompt**
[role + silent protocol + output rules]

---
**User Prompt**
[paste + brackets]
```

3. Keep it human. Contractions, varied length, no robo-words unless you're roasting them.
4. PR description: what it does, where it failed before, one example input/output.

## What gets merged

- Survived 3 real uses, not just "sounds good".
- One idea per prompt. No Swiss Army knives.
- Shorter is better. If you can delete half and it still works, delete half.

## What doesn't

- Prompts that just say "be helpful and thorough" — that's not a prompt, that's a wish.
- LLM-generated slop with no edit. We can tell.
