# Browse

60 prompts, 8 folders. Pick the job, not the title.

```
coding/        — code, review, debug, test, refactor, sql, regex, docs
research/      — fact-check, papers, trends, competitive, deep dive
writing/       — humanize, email, story, threads, linkedin, seo, script
security/      — warden, pentest, privacy
meta/          — architect, optimizer, persona, jailbreak-test
business/      — startup, product, meeting, decision, negotiation, debate, finance, legal
creative/      — brainstorm, poet, image, game, roast, therapist, meme
productivity/  — tutor, interview, career, time, habit, ELI5, travel, cooking, fitness
```

**Fastest way to find one:** `grep -r "keyword" .` — e.g., `grep -r "STRIDE" .`

Or open `../README.md` for the full table with one-line pitches.

No index.html needed — nginx `autoindex` does the browsing when you run docker. For local, just `ls`.
